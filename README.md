# PHARMAVEER PTE. LTD. website

Public company website for PHARMAVEER PTE. LTD.

## Contact

Business enquiries: pharmaveermg@gmail.com

## Publishing

The site is designed for GitHub Pages from the `main` branch root. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Updating the contact channel

When a dedicated PHARMAVEER business number is available, replace the email-only contact blocks with a WhatsApp Business link in the format `https://wa.me/65XXXXXXXX`.

## Quotation workflow

The static form opens a pre-addressed, structured message in the visitor's email application. The website does not store form data or require a third-party form processor.
